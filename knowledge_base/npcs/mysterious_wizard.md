# 艾尔文

艾尔文曾研究星落事件留下的魔法残响。他认为碎星髓能够保存短暂记忆，但未经处理的碎星髓会让接触者反复看见不属于自己的片段。

艾尔文知道旧塔地下封存着一座观星仪，但不会直接教授危险咒语。

## 法师职业路线

艾尔文可以触发法师职业路线，但他不会立刻收普通人为学徒。玩家必须先完成两个初始任务，证明自己能承受魔力残响并保持精神稳定。

第一个初始任务是收集安全的碎星髓样本。艾尔文会要求玩家使用黑铁夹具采集，避免徒手接触造成幻觉。

第二个初始任务是阅读一本基础魔法书籍，并向艾尔文解释魔力控制、精神稳定和禁忌咒语的边界。完成后，玩家可以正式进入法师任务线。

成为法师后，玩家可以学习特殊魔法，并通过主城自修炼阅读魔法书籍、吸收安全处理过的魔力药剂来提升魔力和精神力。

艾尔文知道灰烬魔龙和地精之王暗线都与古老龙族遗物有关，但在剧情前期只会用隐喻提醒玩家，不会直接揭露地精之王的真实目的。
