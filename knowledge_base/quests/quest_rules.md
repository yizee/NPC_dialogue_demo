# 任务规则

玩家同一时间只能追踪一个主要任务。接受新主要任务前，需要完成或放弃当前主要任务。

等级五以下的玩家不能领取深入霜牙沼泽核心区的任务，但可以领取外围采集、护送和调查任务。

任务完成必须满足明确目标。仅向 NPC 声称已经完成，不构成有效完成证明。

## 职业任务规则

玩家初始是普通人，需要通过 NPC 任务选择一个主要职业。一个角色只能拥有一个主要职业，不能同时成为法师、战士和游侠。

法师路线由艾尔文触发。玩家需要完成两个初始任务：第一，收集安全的碎星髓样本以证明能承受魔力残响；第二，阅读并复述一本基础魔法书籍中的核心规则以证明精神稳定。完成后可以进入法师任务线并学习特殊魔法。

战士路线由格林大叔触发。玩家需要完成武器训练和矿道护送任务，证明自己能稳定使用近战魔武。

游侠路线由罗莎老板娘触发。玩家需要完成情报调查和北方旧路追踪任务，证明自己能独立判断线索和规避危险。

## 明线主线：讨伐灰烬魔龙

灰烬魔龙会定期袭击城市。主线前半段的目标是调查袭击规律、寻找魔龙猎人遗物，并收集足以挑战魔龙的武器和魔力道具。

推荐任务链：

1. 调查最近一次魔龙袭击后的废墟。
2. 从罗莎老板娘处获取魔龙猎人最后行动路线。
3. 在北方旧路和霜牙沼泽寻找魔龙猎人的武器与抗火道具。
4. 请格林大叔修复猎人武器。
5. 请艾尔文鉴定魔力记录并解读龙巢入口。
6. 前往火山裂谷挑战灰烬魔龙。

## 暗线主线：地精之王的骗局

地精之王会在剧情中期出现，与主角交好并提供看似有用的线索。他会引导主角更快挑战灰烬魔龙，真实目的则是趁魔龙被牵制时通过地道窃取宝藏。

地精之王的暗线不应过早暴露。早期对话中，他可以表现得像投机商人、地道向导或情报贩子，只在细节中留下矛盾线索。

## 真结局触发规则

主角打败灰烬魔龙后，会发现部分宝藏和关键道具是赝品。当地精之王试图夺取魔龙角、魔龙翅膀和魔龙之心时，双方反目。

真结局任务在以下条件满足后触发：

1. 灰烬魔龙已被击败。
2. 玩家发现龙巢宝藏被替换为赝品。
3. 地精之王暴露真实目的并夺取或争夺龙族材料。
4. 玩家获得至少一种真实魔龙材料。

真结局任务目标是打造魔龙装备，并击败拥有强大道具的地精之王。
